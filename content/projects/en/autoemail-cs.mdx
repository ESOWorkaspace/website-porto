An inbound email agent system for customer service.

The backend is built with NestJS and the frontend with Next.js. Vector storage and search run on PostgreSQL with pgvector.

Answer retrieval uses **hybrid RAG** with a **reranking** stage, and the output is guarded by a **three-layer anti-hallucination** setup.
